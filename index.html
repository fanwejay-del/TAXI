🎤 語音輸入使用說明

【基本用法】

按下首頁最上方的「語音 🎤 輸入」按鈕，跳出視窗後直接說話，倒數結束會自動儲存，完全不用再按任何按鈕。

【怎麼說】

說出「類別 + 金額 + 付款方式」，順序不拘，只要關鍵字有出現就好。

例如：

  • 派遣 100 信用卡
  • 信用卡 150
  • 路招 200
  • 加油 500

【關鍵字規則】

  • 有類別 + 金額 + 付款 → 照你說的記錄
  • 只有金額（例如「150」）→ 類別用第一項、付款用第一項
  • 有類別 + 金額，沒說付款 → 付款用第一項
  • 有支出類別（例如「加油」）→ 記成支出
  • 只說類別，沒說金額 → 會提示「找不到金額」

【聽錯字也沒關係】

語音辨識偶爾會出錯，例如「好孕券」聽成「好運卷」、「企業簽單」聽成「企業千單」。

系統會自動修正常見的錯字 或設定發音容易辨別的名稱例如派遣改成任務，只要關鍵字有兩個字符合就會自動判斷。

【自訂關鍵字】

在設定頁的營業類別、付款方式、支出類型中，點擊「關鍵字」按鈕，可以新增該項目專屬的語音辨識替代詞（例如把「派遣」加上「太淺、台淺」），語音辨識時也會一併比對這些詞。

【注意事項】

  • Android Chrome 才能正常使用，iOS 的 PWA 幾乎無法運作
  • 第一次使用要允許麥克風權限
  • 需要網路連線（語音辨識會送到 Google 伺服器處理）
  • 語速放慢一點，辨識率會更高

【可以調整的地方】

在設定頁可以調整：

  • 倒數秒數：預設 5 秒，可改成 1～30 秒
  • 開關：關閉後首頁不會顯示語音按鈕
  • 營業類別 / 付款方式 / 支出類型：點擊「關鍵字」按鈕可設定額外的語音辨識詞彙

【儲存後】

  • 畫面中央會出現「✅ 已記錄⋯」提示，2.5 秒後自動消失
  • 手機會發出「叮」聲並語音唸出「已記錄 500 元」
  • 首頁列表馬上出現這筆記錄
